# Last Mile Delivery Time Prediction and Route Optimization #

## _PROJECT OVERVIEW_

This project focuses on predicting last-mile delivery times and identifying route optimization strategies for an e-commerce logistics company using data science and machine learning techniques.

> __Dataset Information__
  
 _Dataset: Olist Delivery Time Dataset_ 

|Records: 96,478 |
|----------------|
|Features: 24    |

_Target Variable: delivery_time_days_

> Key Features: 

- distance_km
- estimated_delivery_days
- total_freight
- payment_value
- product_weight_g

## _Project Objectives_

- Analyze factors affecting delivery times.
- Identify logistics performance patterns.
- Preprocess and clean delivery data.
- Perform exploratory data analysis (EDA).
- Build predictive models for delivery time forecasting.
- Propose route optimization strategies.
